# User Approval Policy: Accept & Reject Controls

- **Strict User Review**: All proposed file changes, refactoring, and code executions require explicit user approval.
- **Provide Accept / Reject Controls**: Always provide structured options allowing the user to Accept, Reject, or Modify proposed actions.
- **Planning Mode Requirement**: Always generate an implementation plan artifact with interactive feedback enabled (`RequestFeedback: true`) prior to making modifications to any project files.
